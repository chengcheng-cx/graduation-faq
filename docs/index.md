## 常見問題

??? question "我要出國交換了，可能無法配合廠商時間"
	廠商說可以在學位照期間幫你們進行拍攝，但需要先請你調查班上在11/9-11/19（除了11/11）都可以配合的日子。

	可以的日期和節次給我們。並且要記得提醒班上要拍攝團體照的同學都要填寫畢業服購買表單，確保能在11/5、6這兩天能領到自己的學士服並進行團照的拍攝，謝謝

??? question "研究所的部分團體照是各個實驗室個別時段分開拍，還是會整個所一起拍呢"
	研究所要在同一個時段一起過來拍喔！
	
	不過你們可以想像成一個實驗室一個小組，大家可以各自實驗室分別上鏡。
	只是要以所為單位移動，成品不會有區別

??? question "我是在職班，拍照時間不好喬"
	目前在職班會先以 12/5（六） 拍攝為主，除非有較多在職班無法配合當天拍攝，我們才會再進一步討論是否將在職班的拍攝日期調整至 12/6（日）

??? question "畢業領巾電繡，名字能夠有空格嗎"
	畢業領巾電繡的部分，如果有英文是可以空格的嗎？比如說：Amy Chen。
	
	ok


??? question "拍團體照有什麼限制嗎"
	人數沒有限制，唯一的限制是只有報名團體照的人才可以入鏡拍攝
